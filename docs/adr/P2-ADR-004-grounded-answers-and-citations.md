# P2-ADR-004: Deterministically Validate Grounded Answers and Citations

- **Status:** Accepted for the Project 2 MVP
- **Date:** 2026-11-11

## Context

Answers must use indexed technical documents, cite their sources and abstain when evidence is insufficient. Runbook content and model output are untrusted; a prompt alone cannot enforce source validity or policy.

## Decision

Application determines retrieval sufficiency using a configurable similarity policy calibrated against a versioned evaluation dataset. Below the threshold, it returns `insufficient_evidence` without invoking generation. Otherwise, it requests a strict structured answer and the IDs of cited chunks from the model. It validates the schema, verifies that the answer and citations are non-empty, and confirms that every ID belongs to the results retrieved for that query. It builds citation metadata from persisted records, never from filenames or URLs generated by the model.

## Consequences

- Tests verify citation integrity and abstention without comparing exact generated prose.
- Citation membership demonstrates association with retrieved evidence, not perfect semantic entailment; the product must not claim otherwise.
- Invalid JSON or unknown IDs are explicit output/provider errors, not successful fallbacks.
- Retrieved text is untrusted evidence and cannot trigger tool execution.
